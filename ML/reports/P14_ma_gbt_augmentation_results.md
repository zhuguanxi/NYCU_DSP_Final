# P14 MA-GBT 缺失增強結果

缺失增強提升了 Set C 的 GCS 全遮與六項全遮表現。未遮蔽、六項按 eICU 覆蓋率遮蔽和 eICU Demo 的 AP 都下降。GCS 全遮時，Full／Elastic 相對原版的 AP 各提高 0.0694／0.0657。未遮蔽時各下降 0.1305／0.1342。兩個增強模型的 30 個分裂中，GCS 與 ICU 類型各出現 0 次，機械通氣量測次數出現 9 次。增強版在 GCS 全遮與未遮蔽時的分數相同，機械通氣全遮後的 AP 各下降 0.0309／0.0233。

沿用 [P14 規格](P14_ma_gbt_augmentation_protocol.md) 的 A/B 折分配、原前處理、原版 MA-GBT alpha=1000 與樹設定。4 個 CPU 工作程序完成 14 次 A/B 擬合，模型凍結後只做評估。最終 Full／Elastic 共用同一批遮蔽位置，每組保留 8,000 次 stay 和 1,122 次死亡。

## 限制與產物

- 這輪強度結果適用於原版的固定 alpha=1000、樹容量和每筆一列增強。聯合遮蔽一次改變兩種欄位，評估差值無法單獨歸因給其中一欄。
- 正式 Set C 遮蔽沿用 P9，沒有 ICU 類型單獨遮蔽。A/B 驗證有該情境，eICU Demo 自然包含 ICU 類型與其他量測的覆蓋率落差。
- ρ 衡量預測路徑直接使用補值，量測次數或缺失指標屬於已知輸入。eICU Demo 的區間反映此批小樣本的抽樣波動。
- 完整評估、336 筆逐遮蔽配對彙總、凍結模型與來源雜湊儲存在本機 Git 排除的 `ML/artifacts/ma_gbt_gcs_icu_augmentation/`。
