# P62：MA-GBT 相同容量與無懲罰控制

2026-11-26。補足先前 MA-GBT 固定 10 棵深度 2、XGBoost 300 棵深度 3 的解釋缺口。既有成果不覆寫；本輪全程 CPU，資料、權重、逐筆分數只存 Git 排除的 `artifacts/p62_ma_gbt_matched/`，正式期末報告繼續暫不上傳。

## 固定資料與容量

P12 A/B 8,000 次住院／1,122 次死亡、既有三折、Full／Elastic 各折與全 A/B 的原補值／編碼／欄位。全部新模型固定 300 棵、深度 3、學習率 0.05、log loss、全量行與欄、seed 42，無早停。棵數、深度與學習率與原 Full 一致，但作者 GBT 和 XGBoost 的切分與正則化實作仍不同，不能稱容量完全等價。

## 懲罰與增強的成對控制

使用原鎖定作者版本。無懲罰組在同一 `MAGBTClassifier` 實作中傳 `M=None`，因此不施加缺失懲罰；數值檢查需確認與全零懲罰矩陣的樹相同。正式評估 rho 一律使用真實缺失矩陣，不將無懲罰組錯記為 rho=0。

每組分無增強／GCS60 增強。兩者統一使用 P11 加權副本：只在每個訓練折中選原本有 GCS 的 60%，保留原列與整組 GCS 缺失副本各 0.5 權重，其他原列權重 1，死亡標籤不變、病例總權重不變，抽樣沿原 seed。這次不使用先前 MA 分支的原列直接遮蔽，避免增強形式混雜。

## 僅 A/B 選參

Full／Elastic、無增強／有增強各自比較 alpha 0.001、0.01、0.1、1、10、100、1000，同一網格與三折。每格記錄未遮蔽、GCS 全遮與六欄全遮的 AP／AUROC／Brier／敏感度與 rho；選擇只用未遮蔽 A/B。

同時保留兩個事先固定的選模口徑：

1. AP 口徑：最高三折平均 AP，同分依較低 rho、較小 alpha；作預測能力比較。
2. MA 取捨口徑：AUROC 至少達 MA 候選最佳值 95%，再選最低 rho，同分依較高 AUROC、較小 alpha。這是 MA 候選內門檻，不代表相對無懲罰模型的 95% 保留。

無懲罰組無 alpha 搜尋。總計 96 次 CV 擬合；全 A/B 最終擬合依兩口徑是否選同 alpha 去重，最多 12 次。不依 Set C／Demo、既有最好點估計或新遮蔽分數選擇 alpha／口徑。全部 A/B 候選公開；沒有挑最好種子。

## 凍結後評估

先保存 selection 與 frozen 權重雜湊，才由獨立評估入口讀 Set C 與 Demo。主要隊列保持 Set C 4,000／585、Demo 48h 782／91，沿 P23/P60 明確尿量映射及整點／原始間隔兩種取樣。保留未遮蔽、GCS 全遮、六欄全遮及既有缺失設定；主要比較無懲罰對 MA、增強對無增強，原 Full／GCS-only 為外部演算法參照。

AP、AUROC、Brier、固定 0.5 敏感度、真實缺失路徑 rho 分開報告。固定模型配對區間不涵蓋訓練變異；這輪單一固定種子不能冒稱五種子穩定性研究。舊 MA 10 棵設定只作歷史對照，不將新舊差值全部歸因於樹數。

## 加速與重跑

獨立 `artifacts/p62_ma_matched_runtime/site` 使用 numba 0.60.0／llvmlite 0.43.0；原作者 CPU Python 與 numpy 1.25.2、sklearn 1.5.2 不變。加速僅編譯原切分逐項累積迴圈、快取同一陣列的排序與向量化路徑遮罩；無 fastmath、無近似候選或 binning。需先以 A/B 無懲罰／多 alpha／加權副本比較原樹結構、機率及 rho，逐值一致才執行。

從 ML、原 MA CPU Python、PYTHONPATH 指向鎖定 upstream：`src/train_ma_matched.py check`，再 `src/train_ma_matched.py train --workers 6`。每個擬合獨立保存與續跑，來源雜湊不同就拒絕沿用。程式與結果分開 commit；原始資料與權重不提交。
