# P28 時間窗分流與 Elastic 混合結果

以 A/B 選出的混合在 eICU Demo 尿量對齊後的整點 AP 為 **0.5014**，高於同設定的凍結 Elastic **0.4896**。配對 AP 差為 +0.0119，95% 區間 [−0.0374, +0.0571]。Set C 未遮蔽與 GCS 全遮 AP 各為 **0.5922**、**0.5316**，較 P26 分流低 0.0038、0.0058。

## A/B 選擇

依 [P28 規格](P28_robust_ensemble_protocol.md)，沿用 P12 A/B 的 8,000 次 stay、1,122 次死亡與原三折，在 CPU 重擬 3 個 GCS-only Elastic 訓練折。凍結 Elastic 原三折折外預測與 P26 分流的各情境 AP 均核對。60 個混合配置加上 P26 本身中，41 個通過兩個 AP 門檻。所選為 P26 分流與 GCS-only Elastic 各占 50%，使用 log odds 平均，有無 GCS 均同權重。使用既有凍結模型，最終重擬 0 次。

在尿量對齊的整點設定，P28 比 GCS-only Elastic 高 0.0130，95% 配對區間 [−0.0201, +0.0471]。同一設定下，Brier 為 0.0802，以 0.5 作固定閾值時敏感度為 13.19%。AP 衡量排序，固定閾值結果仍偏低。

混合後在 Demo 的兩種取樣與兩種對齊均提高了相對 P26 的 AP 點估計，四個區間均包含零。Set C 和 Demo 先前已用於多輪分析，獨立患者隊列留待完整版 eICU。完整折外選型、各次遮蔽彙總、配對指標和來源雜湊位於 Git 排除的 `ML/artifacts/p28_robust_ensemble/`。
