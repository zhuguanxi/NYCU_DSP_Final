# P15 MA-GBT 低懲罰對照結果

alpha=10 的增強模型保留了 GCS 數值分裂。與 alpha=10 原版相比，Set C 的 GCS 全遮 AP 提高 0.0692／0.0831，未遮蔽 AP 下降 0.0563／0.0671。與 alpha=1000 的增強組相比，alpha=10 增強在未遮蔽、GCS 全遮、六項按 eICU 覆蓋率遮蔽的 AP 都較高，在六項全遮的 AP 較低。GCS-only 在全部 Set C 情境與兩種 eICU 取樣設定的 AP 皆最高。

依 [P15 規格](P15_ma_gbt_alpha10_protocol.md) 執行。alpha=10 的兩組與各自 Full／Elastic 沿用原補值、欄位編碼、樹設定及 A/B 折分配。全程使用 4 個 CPU 工作程序，完成 12 次三折與 4 次最終擬合。增強組沿用 GCS 45%／ICU 類型 75% 的遮蔽種子，最終每組遮蔽 3,542 筆原有 GCS 和 6,000 筆原有 ICU 類型。兩組模型凍結後才評估 Set C 與 eICU。alpha=1000 的兩組與 GCS-only 沿用已凍結對照。

## 限制與產物

- Set C 沿用 P9 遮蔽，ICU 類型單獨遮蔽屬於 A/B 的診斷。eICU 保留原資料對齊後的缺失型態。ρ 與預測分數分別衡量補值使用和辨識能力。
- eICU Demo 樣本已用於前兩輪比較，這輪採相同樣本衡量相對變化。
- 完整 Brier、0.5 門檻敏感度、配對彙總、模型及來源雜湊保存在 Git 排除的 `ML/artifacts/ma_gbt_alpha10/`。報告只包含彙總數字。
