# P41 P12 結果時間稽核與 Set C 敏感度分析

本機 A、B、C 三份結果表的 SHA-256 均與 PhysioNet v1.0.0 的公開檔案相同。三份欄位中的住院死亡標籤與原研究一致。依 [P41 規格](P41_p12_outcome_timing_protocol.md) 用 CPU 重現全 Set C 的未遮蔽、GCS 全遮及六項全遮結果，再依時間欄位取子群。全程使用原標籤和模型，擬合 0 次。

## 結果欄位核對

官方說明指出，P12 排除 ICU 停留不足 48 小時的紀錄。Length of stay 從 ICU 入住計至出院，Survival 以整天記錄從入住到死亡的時間。公開結果表有以下分布。表中每格為 stay 數／原住院死亡數。[PhysioNet 2012 資料與結果欄位定義](https://physionet.org/content/challenge-2012/1.0.0/#outcome-related-descriptors)

| 結果欄位 | Set A | Set B | Set C |
| --- | ---: | ---: | ---: |
| Length of stay 小於 0 | 60／0 | 54／0 | 53／0 |
| Length of stay 為 0 或 1 | 1／0 | 2／0 | 2／1 |
| Survival 為 0 或 1 | 29／26 | 25／24 | 37／35 |
| 任一時間欄位為 0 或 1 | 30／26 | 26／24 | 38／35 |
| Length of stay 為 2 | 50／20 | 54／15 | 73／27 |
| Survival 為 2 | 57／56 | 61／60 | 86／86 |

在 Set C 的 35 個 Survival 為 0 或 1 的住院死亡病例中，35 個在 ICU 入住 24 小時後仍有至少一筆有效觀測，34 個在第 36 小時或更晚仍有觀測。這項核對使用序列模型的 20 個觀測通道。資料只提供整天結果欄位及代表入住後時間的觀測分鐘，無法確定這些病例的精確死亡時間或 ICU 離開時間。Set B 另有一個 Survival 值小於 −1 的住院存活病例。
