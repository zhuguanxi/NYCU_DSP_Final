# P30 Set C 全遮蔽的配對比較

P26 分流在 Set C 的 GCS 全遮與六項全遮時，相對 GCS-only Full 的 AP 差各為 +0.0324、+0.0388，配對 95% 區間均高於零。P28 混合在這兩種情境也高於 GCS-only Full，與 P26 的差距仍不確定。

沿用 Set C 的 4,000 次 stay、585 次住院死亡及 [P9](P9_missingness_protocol.md) 固定遮蔽。六項為 GCS、乳酸、侵入式 MAP、鎂、尿量及機械通氣。CPU 重新計分，逐值核對未遮蔽、GCS 全遮與六項全遮的歷史 AP、AUROC、Brier 和 0.5 門檻敏感度。模型重擬 0 次。

每種情境使用原 Set C 固定種子的 2,000 次 stay 配對 bootstrap。每次在同一批抽樣上重算所有比較的 AP 與 AUROC，以 2.5 與 97.5 百分位估計區間。
