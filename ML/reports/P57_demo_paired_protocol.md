# P57：24 小時外部增強與 A/B-only 混合的配對比較

2026-11-22。補齊 P52 未比較 P50 的缺口，並檢查患者與院鍵區塊兩種變異。這是同一 Demo 的探索性分析，不是新的獨立醫院驗證。

1. 固定 P49/P52 的所有權重、輪次及參數。重建原 24 小時 Demo 1,398 次住院／121 次死亡及兩種取樣；APACHE 共同隊列沿原 1,166／100。需重現 P49/P52 保存的各項指標。
2. P50 未保存逐筆折外分數，因此按原患者連結院鍵區塊五折、原 seed 及原 augmentation 配方重擬五次有 GCS 分支，還原原 Demo 折外分數；不得用 P50 全 Demo 最終模型回測 Demo。只重現既有配置，不選新參數；原 P50 指標必須重現。
3. 主要新增比較 P52 減 P50；同時列 P52 減 P49，及共同隊列 P52 減 APACHE IVa。兩種取樣都完整呈現。AP、AUROC、Brier 都報告，不因某指標未改善就改用另一指標宣稱同一假設成功。
4. 每種比較用 1,000 次患者配對重抽，以及 1,000 次患者連結院鍵區塊配對重抽，seed 42。驗證原 P52 對 P49 的患者區間一致。分組鍵依發布的 hospitalid 建立；其實際醫院含義有既有不確定性，不把院鍵數稱為確定醫院數。
5. 有／無 GCS 僅作事先指定的分層描述。無 GCS 時 P50/P52/P49 分數應逐值相同，需核對。資料、患者／院鍵、折外機率、重現權重皆留在 Git 排除的 `artifacts/p57_demo_paired_completion/`。

接受負向或不確定的結果，不調整病例、抽樣種子、分折或信賴區間以取得正向結論。程式與彙總結果分開 commit 並推 GitHub。
