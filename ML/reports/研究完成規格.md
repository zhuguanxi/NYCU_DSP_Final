# 現有資料下的研究完成規格

2026-11-22。使用者已確認只有 eICU Demo，先完成現有資料能做的研究；不製作簡報、封面或分工表，只完成實驗並提供研究故事。先前取消的 R1 不恢復。

## 目標與驗收證據

1. 未遮蔽死亡排序：核對 P33、原 Full／Elastic、KEDGN A+B 在同一 Set C 和 Demo 的凍結指標與配對差，對應 P41／P54 及本輪彙總。
2. 缺失韌性：保留 P9–P20 的增強與 MA-GBT 消融、P30 固定遮蔽比較；P55 加入 Set A 與 A+B KEDGN 的同通道完整遮蔽，補足競爭基準。
3. 同一可執行模型：P56 僅用原 A/B 三折重現 P33 神經折外分數，再選擇觀測狀態條件下的混合規則。若未通過 A/B 預設條件則保留既有模型，記錄失敗，不用 C／Demo 翻案。
4. 跨資料集：核對純遷移與 Demo 分組折外外部增強的差異，補齊 P52／P50 的同患者配對比較與分層、院鍵敏感度；不把交叉驗證或反覆查看的 Demo 稱為全新外部驗證。
5. 24 小時延伸：與 48 小時分開呈現，保留風險集代理、APACHE 共同隊列及時間可得性限制。
6. 文獻基準：KEDGN 與 MA-GBT 為已實際重現的比較；其餘文獻的原報值、未完成部分、切分／標籤／變體差異分開列，不冒充同隊列 SOTA 排名。
7. 結果交付：只含整體統計的實驗登錄、圖表、來源雜湊、可重跑程式、主要結論與研究敘事。程式／結果分開 commit 並推 GitHub；資料、權重、逐筆分數、折外預測不進 Git。

## 判讀原則

目標是用充分實驗回答三個問題；正向假設不能事先保證。若 Demo 的區間仍跨零，明確寫為外部改善未確定，並說明能支持的韌性、校準或機制發現。不透過反覆挑 Demo／Set C 表現、放寬門檻或挑子群來宣稱目標已達成。

本規格不包含課程影片、簡報、正式上傳或尚不存在的完整 eICU 結果。這些依使用者最新指示不屬本輪交付。
