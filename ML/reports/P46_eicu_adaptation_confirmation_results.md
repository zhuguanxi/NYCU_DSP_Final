# P46 完整 eICU 的 P45 確認入口

依 [P46 規格](P46_eicu_adaptation_confirmation_protocol.md)，把 P45 加入同隊列確認。主要對照為 P28 對原凍結 Elastic。P38 與 P45 為次要候選。納入時間窗、住院死亡標籤、尿量 mL 對齊和患者抽樣均沿用 P40。P45 使用 P44 凍結的時間窗 XGBoost，配上原無 GCS 分支和 P28 混合成分。全程 CPU，擬合 0 次。

## 正式路徑的合成核對

用原 Demo 的患者與 stay 識別鍵核對排除參照，另加 32 筆無重疊的合成病例，以及一筆同一 Demo 患者的額外 stay。合成觀測用於檢查輸入、推論和分數彙總流程。實際保留的 32 筆與預期完全一致，包含 16 筆無 GCS。這 16 筆 P45 的分數逐筆等於 P28。P45 對 P28、P38、凍結 Elastic 的配對欄位皆可輸出。此測試的配對次數設為 30，正式設定仍為 1,000。試算數值在發布前攔下，正式輸出路徑保持空白。

## 實際 Demo 試跑

使用全部 782 次合格住院、719 名患者、91 次住院死亡，重現 P40 的兩種取樣。原 P28、原凍結 Elastic、P38 等對照的指標與配對區間逐值相同。也已核對 63 個既有模型與研究產物雜湊。

| 取樣 | 推論住院數 | 無 GCS，P45 與 P28 逐筆相同 | 有 GCS，P45 與 P28 分數不同 |
| --- | ---: | ---: | ---: |
| 整點 | 782 | 199 | 583 |
| 原始間隔 | 782 | 199 | 583 |

P45 在此試跑僅保存上表的功能檢查。正式模式拒絕直接把這個 Demo 目錄當輸入。正式效能需先取得有授權的完整版 eICU v2.0。本機目前的產物為 Git 排除目錄 `artifacts/p46_demo_smoke/` 下的試跑彙總。取得完整資料後，依 [CPU 入口](P46_eicu_adaptation_confirmation_protocol.md) 指定完整資料目錄。
