# P63 報告統一口徑

依使用者 2026-11-28 指示，正式六模型比較只採每個種子分別評估，再報五次指標算術平均與樣本標準差（ddof=1）。不使用跨種子機率集成、不挑最好種子，不以單種子結果替代五次平均。

六模型固定為原 XGBoost Full、P22 時間窗 XGBoost、P62 MA-AP Full＋GCS60、P28 表格混合、KEDGN A+B 與 R1 XGBoost 論文參數版。AP、AUROC、Brier、固定0.5敏感度均按同一規則整理；病例、標籤、訓練及評估輸入與原 P63 一致。Set C 未遮蔽、GCS全遮、六欄全遮，以及 eICU Demo 整點／原始間隔分開呈現。

「每個種子一次預測」沿用各方法原架構。P28 本身的 P26／GCS-only Elastic 混合是方法的一部分，保持原 A/B 選定權重；禁止的是額外平均五個種子版本的機率。方法架構、特徵表示或模型容量不同的限制仍需揭露，統一彙整方式不等於所有模型具有相同結構。

一般模型 seeds42–46；KEDGN 沿既有0–4，不視為跨模型有意義的配對隨機種子。零標準差保留，表示這些固定配置未觀察到種子差異，不代表零預測誤差、五份獨立測試或跨院穩定。這次不重訓、不改參數、不改訓練切分，也不以 Set C／Demo 選擇模型。
