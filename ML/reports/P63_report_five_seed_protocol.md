# P63：期末報告模型的固定五種子補齊

2026-11-28。依使用者要求，補齊報告用權重及共同評估，不重新搜尋參數、選欄、輪次、alpha、增強強度或混合權重。原始資料、權重、輸入快取與逐筆預測全部留在 Git 排除的 `ML/artifacts/p63_report_five_seed/`。正式報告草稿及 PDF 仍維持本機。

## 報告範圍

主模型為原 XGBoost Full、P22 時間窗 XGBoost、P62 MA-AP Full＋GCS60、P28 表格混合、KEDGN A+B 重訓、R1 XGBoost 論文參數版。必要支持組包括 P11 GCS-only Full、P26 分流、原 Elastic／GCS-only Elastic、R1 容量對齊版，以及 P62 Full 的同作者無懲罰／MA-AP／MA-rho95，各自分無增強及 GCS60；合計 16 個固定預測程序。

一般種子固定 42–46，KEDGN 沿作者既有 0–4，不視為相同隨機實驗的配對種子。重用原 P60 全部五種子權重和逐筆預測；P22 使用同批已保存且 seed42 曾逐值核對原 P22 的時間窗分支，補其獨立預測。KEDGN 沿已凍結五套 A+B 權重與預測，不重新訓練。

## 新增訓練

P62 只擴充 Full 六個已選定程序：無增強 off／alpha0.1／alpha1000；GCS60 off／alpha0.001／alpha1000。seed42 沿原模型，43–46 各新增六次最終 A+B 擬合，共 24 次。所有新 MA 固定 300 棵、深度3、learning_rate0.05、原作者 CPU 實作與原 Full 最終補值／編碼。GCS60 加權副本位置固定，保留每病例總權重和正例權重。較快的樹落點編譯版本需先在 A/B 核對原訓練樹及機率完全相同，六程序各兩次三樹診斷，共 12 次短診斷擬合，與正式擬合分開記錄。

R1 沿新匯入快照的 148 欄摘要、A+B 原始有效觀測補值及兩套固定樹參數。seed42 使用原匯入模型，其餘四種子各擬合兩套，共八次。沒有新增 R1 交叉驗證或搜尋；原作者分割的論文精確復現不屬此階段。來源特徵函式保留原計算，先核對 A/B 觀測數、重複分鐘處理與補值均值。原快照內的歷史 170 次預算不是本階段新增訓練上限；本階段依使用者明確要求新增 32 次正式擬合，另有上述 12 次診斷。

全部新增擬合只用 P12 A+B 8,000／1,122。採原 CPU 訓練演算法保持裝置口徑；使用者允許 GPU，但不為使用 GPU 改變原算法、裝置與數值設定。全體權重與預處理來源先核對並封存，才開始本輪新增測試預測。

## 評估與公開

共同五情境：Set C 未遮蔽、GCS 全遮、六欄全遮，以及明確尿量映射的 eICU Demo 整點／原始間隔。病例與標籤同原 P60/P62：Set C 4,000／585、Demo 782／91。五套模型全部報告 AP、AUROC、Brier、固定0.5敏感度；MA 另列直接讀補值的路徑 rho，不把缺失旗標的使用當作直接補值。

先計算每種子的指標，再列算術平均、樣本標準差 ddof=1、最小及最大值；不能挑最好一次。五種子機率平均的集成另列，不能與五次指標平均互換。Full 或 R1 等確定性設定即使五次相同，也如實報告 SD=0，不當作五份獨立測試證據。GCS 增強位置固定，因此這輪不涵蓋增強抽樣、重新選參或資料切分的不確定性。

本階段不重跑整個 P9 位置矩陣或 P61 連續時間缺失；這些既有結果另保留，不能把新模型五情境結果宣稱成完整時間缺失驗證。報告用模型對比可列各種子的差值及平均，但 KEDGN 的種子索引不能與其他模型當成有意義的一一隨機配對。既有患者 bootstrap 區間不直接附到新的五次平均上。

公開內容只含整體指標、來源雜湊、完整種子清單、權重完整性檢查與重跑方式。Set C／Demo 已反覆使用，這輪為固定配置補強，並非新的獨立泛化確認。程式／規格與結果分開提交，資料、逐筆預測、模型與正式報告不進 Git。
