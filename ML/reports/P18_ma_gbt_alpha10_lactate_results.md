# P18 MA-GBT 乳酸缺失增強結果

乳酸增強讓 eICU Demo 的補值乳酸依賴由 27.11%／27.11% 降至 0%／0%，尿量依賴維持 0%。整點 eICU 的 AP 點估計較 P16 尿量增強低 0.0285／0.0489，兩個配對 95% 區間均包含零。Set C 乳酸全遮與新模型未遮蔽的 AP 一致，GCS 全遮相較 P16 小降 0.0021／0.0048。各處雙值依序為 Full／Elastic。

依 [P18 規格](P18_ma_gbt_alpha10_lactate_protocol.md) 執行。全程 CPU，完成 12 次 A/B 三折擬合及 2 次最終擬合。兩組最終各用原 8,000 次 stay 與 1,122 次住院死亡，GCS 3,542 筆、ICU 類型 6,000 筆及尿量 5,840 筆的遮蔽延續 P16，另遮蔽 1,100 筆原有乳酸。新模型凍結後才讀取 Set C 與 eICU。

## 限制與產物

- 補值依賴率計算預測路徑直接使用補值的比例。同一筆預測可使用多欄補值。量測次數與缺失旗標屬於已知輸入。Set C 的遮蔽 AP 量測效能變化。
- eICU Demo 固定原欄位對齊及未映射處理，且即為先前使用的樣本。配對區間反映目前 cohort 的抽樣變動。
- 完整模型、Brier、0.5 門檻敏感度、補值路徑逐欄統計及 336 筆配對彙總存於 Git 排除的 `ML/artifacts/ma_gbt_alpha10_lactate/`。
