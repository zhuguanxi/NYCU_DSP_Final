## 適用範圍與重現

Set C 與 eICU 已用於早期評估，此處是同一批病例和相同輸入條件的回溯比較。選擇及重新擬合只用 A/B。訓練本質上是有觀測者中的人工 GCS 遮蔽，與其他欄位的共同缺失、量測頻率及病例組成仍可能影響外部結果。

從 `DSP` 的 PowerShell 執行以下命令。輸出目錄須為新路徑。比較入口採用既有 P10 的模型及評估結果。

```powershell
.\ML\.venv\Scripts\python.exe .\ML\src\train_missingness_augmentation.py --gcs-only --output .\ML\artifacts\gcs_only_AB_rerun
.\ML\.venv\Scripts\python.exe .\ML\src\evaluate_missingness_augmentation.py --models .\ML\artifacts\gcs_only_AB_rerun --output .\ML\artifacts\gcs_only_evaluation_rerun
.\ML\.venv\Scripts\python.exe .\ML\src\compare_gcs_augmentation.py --models .\ML\artifacts\gcs_only_AB_rerun --evaluation .\ML\artifacts\gcs_only_evaluation_rerun --output .\ML\artifacts\gcs_only_comparison_rerun
```

本次模型及 A/B 記錄位於 `ML/artifacts/gcs_only_augmentation_AB/`。既有評估格式的輸出位於 `ML/artifacts/gcs_only_augmentation_evaluation/`。三組對照表、336 筆遮蔽配對彙總和四組 eICU 摘要位於 `ML/artifacts/gcs_only_comparison/`。資料、模型和本機輸出均由 Git 忽略。
