# P54：A+B 重訓 KEDGN 的凍結轉移結果

依使用者指示，以 P12 A/B 開發並完成五種子重訓後，再評估 Set C 與 eICU Demo。訓練可使用 GPU，正式比較沒有新增擬合，R1 不復現。資料、折外機率、逐筆預測與權重留在 Git 排除目錄，本報告及 JSON 僅含整體統計。

2026 年 11 月 21 日完成。程式與核對流程已先提交至 `5b31125`（GPU 遮罩運算實作見 `dd9cebc`），本報告與結果彙總另行提交。

## 結果判讀

- **Set C 相對 Set A 凍結版的改善有配對區間支持。** AP 由 0.54977 升至 **0.57502**，差 **+0.02525 [+0.00836, +0.04363]**；AUROC 由 0.86636 升至 **0.87790**，差 **+0.01155 [+0.00673, +0.01619]**。
- **尚未超過本組主要對照。** 對 Full 的 Set C ΔAP 為 **−0.00483 [−0.02781, +0.01891]**，差異未確定；不能據此宣稱兩者等效。對 P33 為 **−0.02945 [−0.05037, −0.00752]**，本輪 AP 仍較低。
- **eICU 改善仍不確定。** 整點 AP **0.46375**，對 Set A 的差為 **+0.01378 [−0.04314, +0.06213]**；原始間隔 AP **0.44640**，差為 **+0.00045 [−0.05022, +0.04733]**。兩種取樣對所有原模型的 AP 差值區間也都跨零，不能宣稱跨庫提升。
- **機率誤差仍需分開判讀。** A+B 版三個隊列的 Brier 均低於 Set A 版，但仍高於七組本組對照。固定 0.5 門檻敏感度的高低不等於整體分類或臨床效益；本輪未重新校準或選門檻。

本輪證據支持這套 A+B 訓練方案改善 P12 留出集的 KEDGN 表現；Set A 與 A+B 版本還有選輪次方式的差異，因此不能將全部收益單獨歸因於訓練量。外部轉移仍是後續需要獨立確認的問題。

## 主要結果與配對比較

AP、AUROC 越高越好，Brier 越低越好。敏感度沿用固定 0.5 門檻，未在測試集校準或選門檻。差值方向為 A+B KEDGN 減對照。Set C 用 2,000 次住院配對重抽；eICU 用 1,000 次患者分組配對重抽，沿用 P53 種子。區間未作多重比較修正。

## 判讀與限制

A/B 原始解析保留全部 8,000 筆，包括作者 36 通道下的 10 筆零觀測病例，按欄位名處理 189 筆入院欄位順序或缺漏不同的紀錄。P53 的 Set C／eICU 輸入、病例順序與標籤逐值核對一致。初次逐點 GPU 執行因效率中止，保留本機紀錄，未納入輪次選擇或測試。

五個最終模型另外以包含零觀測病例的 8 筆 A/B 探針，逐一核對原作者 CPU 與批次 GPU 推論，最大 logit 差約 **7.2×10⁻⁷**，全部通過容差。這是訓練後推論一致性核對，不是額外模型選擇。

本輪與本組原模型的訓練病例量皆為 A+B 8,000 筆，但 KEDGN 使用作者 36 通道、9 維靜態和正值 mask，表格模型使用不同特徵表示。保留作者平衡採樣與有效 batch 256。GPU 使用等價遮罩圖運算及 batch 256，正式訓練前核對與原作者的 logits、全部有效參數梯度，以及整批／分批梯度；FP32、關閉 TF32，啟用確定性運算。

P53 Set A 模型只有 3,198 筆訓練，且以作者 400 筆驗證選 checkpoint；本輪以三折選共同輪次。差值同時包含訓練資料、選擇方式與五種子訓練變異，不宜單獨歸因於訓練量。作者驗證程式用 sigmoid 單類 logit，本輪沿最終測試用雙類 softmax，輪次選擇也一致使用 softmax AP。

Set C 使用 P53 相同完整 4,000 筆，與 A/B ID 互斥；eICU 使用相同尿量 mL 對齊及兩種取樣，長序列不截斷。Set C 已反覆查看，eICU Demo 僅 91 次死亡；固定模型的配對區間未涵蓋重新訓練及跨醫院變異。P45 使用 Demo 做增強、P52 使用 24 小時窗，未在本輪 48 小時純轉移比較中混合排名。本輪沒有新增遮蔽測試。
