## 目前實際 pipeline

1. **原始資料與標籤**：P12 A/B/C 與 eICU Demo；住院死亡分類。清理負哨兵、非有限值與無效類別，依觀察窗截取；eICU 核對欄位、單位、GCS／通氣定義與尿量 mL 事件。識別鍵、出院資訊、結局時間及臨床評分不作模型輸入。
2. **三種輸入**：435 欄表格摘要與缺失旗標；20 通道的 140 個時間摘要；20 通道逐小時數值與觀測旗標。補值、編碼及序列縮放僅由相應訓練部分估計。
3. **48h 主模型 P33**：P26 有／無 GCS 專家 → P28 對數勝算混合 → 75% P28 機率 + 25% 逐小時 CNN 機率。P56 僅用 A/B 檢查條件混合，未勝出，因此不改原 P33。
4. **對照**：凍結 Full／Elastic、GCS-only Full／Elastic、P26／P28、作者 MA-GBT 及 KEDGN。KEDGN 另有作者 Set A 版與共同 A+B 版，不能混報。
5. **凍結評估**：Set C 未遮蔽、六個單欄全遮及聯合全遮；eICU 同病例整點／原始間隔轉移。固定模型的配對統計與重新訓練變異分開解讀。
6. **外部增強與 24h 延伸**：P45／P50 用患者連結院鍵區塊五折，測試折不參與擬合；P52 是 24h P12-only 混合。24h 與 48h 為不同風險集，分開計分，APACHE 只在同窗共同隊列比較。

原流程及細節：[P0](P0_資料與特徵重建.md) · [P8](P8_eicu_demo_protocol.md) · [P26](P26-P27_gcs_routing_results.md) · [P28](P28_robust_ensemble_protocol.md) · [P33](P33_hourly_sequence_protocol.md) · [P49](P49_24h_landmark_protocol.md)。
