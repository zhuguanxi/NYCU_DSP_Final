# P10 A/B 缺失增強訓練規格

以原 P12 A/B 的 8,000 次 ICU stay 和 `folds3.csv` 為開發資料。使用既有三折 Full／Elastic 的有序特徵、折內補值與編碼器，以及 XGBoost 原設定。以同一組全 A/B 預處理器和各自選定的欄位建立最終增強模型。使用 CPU 2 執行緒，原凍結管線照常作為比較基準。以下規格在新模型評分前固定。

## 增強與 A/B 選擇

- 依 [P9 遮蔽規格](P9_missingness_protocol.md) 同步處理 GCS、尿量的摘要、次數與缺失旗標。從訓練折原本有觀測的 stay 中不放回選取。兩個通道分開抽樣，各模型共用遮蔽配置。
- 比較兩個強度。中度遮蔽率為 GCS 25%、尿量 75%，強度較高方案為 GCS 60%、尿量 100%。比例為各通道有觀測的訓練樣本中用於產生遮蔽副本的比例。每個受到遮蔽的 stay 保留原列和一個遮蔽副本，各權重 0.5。其餘原列權重為 1，每個來源 stay 的總權重相同。
- 以 Full 的既有三折比較兩個強度和原凍結折模型。每一折的驗證情境均含原始資料、三次 GCS 25%＋尿量全遮，以及一次 GCS 和尿量都全遮。遮蔽按照固定種子產生。先等權平均兩種缺失情境的 AP，再平均三折作為缺失評分。
- 在原始驗證平均 AP 較 Full 基準下降至多 0.0100 的增強方案中，選缺失評分最高者。若兩案都超過 0.0100，選原始平均 AP 較高者，並標記未通過此條件，以供對照。以中度、強度較高的順序解決完全同分。
- 選定同一強度供 Full 與 Elastic 共用，再完成 Elastic 的三折診斷。Elastic 不重新挑強度。最後各用全 A/B 增強資料重新擬合一次 XGBoost。預計 11 次新擬合，另存本階段紀錄。

## 凍結後評估

- Set C 使用 [P9](P9_missingness_results.md) 原本 4,000 筆、13 種遮蔽及相同的遮蔽位置與重複，另核對未遮蔽結果。
- eICU Demo 使用 [P8](P8_eicu_demo_results.md) 原本隊列、每小時與原生頻率兩套特徵、院內死亡標籤、病人叢集 bootstrap 和 0.5 閾值。
- 主要觀察 P9 六項按 eICU 覆蓋率聯合遮蔽，以及 P8 每小時取樣的 AP，並一起呈現 AUROC、Brier、原閾值敏感度與原始 Set C 表現。差值定義為增強模型減原凍結模型。Set C 和 eICU 的資料與結果僅在增強方案選定並保存模型後讀取作評估。兩批隊列已用於先前評估，這輪為沿用既有測試條件的回溯比較。

模型、原始資料、逐筆特徵與本機輸出留在 Git 排除路徑。
