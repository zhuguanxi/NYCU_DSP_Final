# P21–P25 ICU 死亡預測效能改進

未遮蔽 Set C 的最高 AP 為時間窗 XGBoost 的 0.5947，原凍結 Full 為 0.5798。配對 AP 差為 +0.0149，95% 區間 [+0.0010, +0.0288]。eICU 補回明確尿量後，整點的最高 AP 為原凍結 Elastic 的 0.4896。該模型相對自己原對齊的 AP 差為 +0.0129，配對 95% 區間跨零。

共同預測任務使用 ICU 入住後 48 小時內的輸入與住院死亡標籤。P21 和 P22 只在原 A/B 8,000 次 stay 及同一三折選型，先凍結模型再讀 Set C 或 eICU。Set C 有 4,000 次 stay、585 次死亡，eICU Demo 有 782 次 stay、719 人、91 次死亡。這兩個隊列在先前實驗均曾使用。全程 CPU。

## A/B 開發

P21 使用原 P12 欄位、原生 NaN、對齊特徵子集、固定缺失增強及預先指定的機率混合。完整候選與隨機種子見 [P21 規格](P21_predictive_boosting_protocol.md)。完成 63 次正式 A/B 訓練折擬合，加 1 次全 A/B 新模型擬合。原凍結模型各折 OOF 逐值核對。

| --- | ---: | ---: | ---: | ---: |
| 原凍結 Full | 0.5450 | 0.4901 | 0.4448 | 0.5212 |
| GCS-only Full | 0.5448 | 0.5009 | 0.4890 | 0.5282 |
| P21 未遮蔽首選 | 0.5649 | 0.5070 | 0.4639 | 0.5403 |
| P21 韌性加權首選 | 0.5638 | 0.5058 | 0.4865 | 0.5416 |
| P22 同模型原摘要 650 棵 | 0.5545 | 0.4982 | 0.4580 | 0.5308 |
| P22 小時時間窗 650 棵 | 0.5537 | 0.5021 | 0.4653 | 0.5319 |

P21 未遮蔽首選與韌性首選的實際配置分別為 `frozen_full+cat7_aligned_plain_650:0.50`、`gcs_only_full+cat7_aligned_plain_650:0.50`。P22 採相同 XGBoost 樹設定，在原摘要上增加 20 組訊號各 7 個小時特徵。先算逐小時中位數，再計前 12 小時與最後 12 小時的平均、晚期最小最大、兩窗平均差、距最後觀測時間及觀測小時數。最後的 2,880 分鐘觀測納入第 48 小時。訓練與驗證的時間窗均受 48 小時截斷，遮蔽時連帶更新對應時間特徵。完成 6 次 A/B 折擬合和 1 次全 A/B 擬合。

## 目前研究判定

時間窗模型提供了目前最強的未遮蔽 Set C 分數，且六項匹配遮蔽 AP 為 0.5361。全遮 GCS 仍由 GCS-only Full 的 0.5049 領先，P21 韌性加權混合模型的 AP 為 0.4993。eICU 的兩種新模型在補回尿量後，整點 AP 仍低於用同一映射的原凍結 Elastic。現有結果支持提高 Set C 表現並修正確有來源的外部缺失。整體跨資料集改善仍待同一個模型在獨立隊列驗證。
