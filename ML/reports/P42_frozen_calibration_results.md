# P42 凍結模型的機率校準與分類門檻結果

依 [P42 規格](P42_frozen_calibration_protocol.md) 使用 CPU。在 8,000 次 A/B stay、1,122 次住院死亡的折外分數上，擬合五組邏輯校準係數及分類門檻。P33 和 P38 共重現六次原序列訓練折。新基礎模型擬合 0 次。三種 Set C 情境、四種 eICU Demo 設定的原分數均與既有評估一致。校準前後的 AP 和 AUROC 一致，轉換後的 A/B 門檻逐筆重現原門檻的分類。

## 機率誤差

Brier 差值取校準減去原值，負值代表誤差下降。Set C 使用 2,000 次 stay 配對 bootstrap，eICU Demo 使用 1,000 次患者配對 bootstrap。

| 模型 | Set C 未遮蔽原／校準 Brier | 配對差 95% 區間 | eICU 尿量對齊整點原／校準 Brier | 配對差 95% 區間 |
| --- | ---: | --- | ---: | --- |
| 凍結 Full | 0.087356／0.087235 | [−0.000433, +0.000198] | 0.080206／0.079829 | [−0.000942, +0.000147] |
| 凍結 Elastic | 0.088085／0.087931 | [−0.000441, +0.000142] | 0.079316／0.078989 | [−0.000856, +0.000197] |
| P28 | 0.086050／0.085794 | [−0.000655, +0.000160] | 0.080154／0.079322 | [−0.001579, −0.000148] |
| P33 | 0.085120／0.084942 | [−0.000797, +0.000480] | 0.080955／0.080542 | [−0.001582, +0.000679] |
| P38 | 0.085478／0.085125 | [−0.000752, +0.000073] | 0.079810／0.079051 | [−0.001477, −0.000098] |

五個模型在未遮蔽 Set C 的 Brier 點估計都下降，區間均包含零。GCS 全遮和六項全遮下，凍結 Full、Elastic、P28 和 P38 的誤差下降區間均在零以下。P33 在兩種遮蔽下也下降，區間包含零。

在 eICU 尿量對齊整點，P28 的 Brier 差為 −0.000832，P38 為 −0.000760。兩者相對各自原機率的區間均低於零。凍結 Elastic 校準後仍有最低 Brier 點估計 0.078989。在原始間隔及原對齊的其餘三種 eICU 設定，五組配對區間都包含零。

## 分類門檻與 PhysioNet 指標

Event 1 取敏感度與陽性預測值（PPV）的較小值，越大越好。下表列由原 0.5 門檻改用 A/B 選定門檻的變化。Event 2 越小越好，Set C 的計算以 `score.c` 為準。已用 4,000 筆合成案例核對官方程式輸出，涵蓋同分時按編號排序。[PhysioNet 評分程式](https://physionet.org/content/challenge-2012/1.0.0/score.c)

| 模型 | Set C 未遮蔽 Event 1 | Set C GCS 全遮 Event 1 | eICU 尿量對齊整點 Event 1 型指標 | Set C 未遮蔽 Event 2，原／校準 |
| --- | ---: | ---: | ---: | ---: |
| 凍結 Full | 0.34530 → 0.53431 | 0.10427 → 0.26154 | 0.17582 → 0.37363 | 20.72460／14.23769 |
| 凍結 Elastic | 0.31453 → 0.53488 | 0.11282 → 0.25299 | 0.18681 → 0.38462 | 25.58619／18.64587 |
| P28 | 0.34017 → 0.55740 | 0.22735 → 0.45983 | 0.13187 → 0.34066 | 25.21241／14.81148 |
| P33 | 0.35043 → 0.53364 | 0.21026 → 0.44444 | 0.13187 → 0.40659 | 15.18397／8.49145 |
| P38 | 0.33162 → 0.54701 | 0.20000 → 0.39487 | 0.13187 → 0.32967 | 29.79153／15.36576 |

三種 Set C 情境與四種 eICU 設定中，五個模型使用 A/B 門檻時，敏感度都提高且 PPV 都下降。以 P28 為例，未遮蔽 Set C 的敏感度由 0.34017 升至 0.57265，PPV 由 0.69097 降至 0.55740。P28 在同一套門檻挑選規則下有最高未遮蔽 Set C Event 1 點估計。P33 有最低的未遮蔽 Event 2 點估計及最高的 AP。Event 1 與 Event 2 比較為點估計。

本研究使用 A/B 開發並多次評估 Set C 及 Demo。挑戰賽分數適用於本研究同隊列比較，歷史正式比賽有不同開發流程。跨庫結果的區間為探索性配對比較，尚需有授權的完整 eICU 確認。既定 [P40 獨立外部驗證](P40_eicu_sequence_confirmation_protocol.md) 使用原凍結模型。

完整七種情境、分類指標、係數與資料雜湊保留在 Git 排除的 `artifacts/p42_frozen_calibration/summary.json`。
