# P56：只用 A/B 選觀測狀態條件混合

2026-11-22，針對研究的「完整資料與缺失時能否兼顧」補一個明確的單一模型實驗。不是從 Set C 的各情境贏家事後拼接規則。

## 事先規格

重現 P33 已選定的 plain CNN、8 輪、seed 2026111733+fold、CPU Torch 2.1.2、三執行緒。使用原三折與原六種驗證視圖（clean、shift1/2、mapped1/2、full_gcs），每折只在其訓練部分估計縮放。只重擬此一固定配置，共 3 次 CNN 擬合，需逐項重現 P33 原候選的 A/B 分數，才能選新規則。

P28 的折外分數直接沿用 P33 已核對的 anchor；P26 由保存的原折外分支分數及原路由規則重建，需重現原 A/B 指標。GCS 是否可得由當前輸入決定，未使用標籤或未遮蔽的隱藏欄位。

候選 32 個：有 GCS 時以 P28 為表格成分，序列機率權重取 {0, 0.15, 0.25, 0.50}；無 GCS 時表格成分取 P26 或 P28，序列權重取相同四值。主目標沿 P33：clean 35%、mapped 35%、shift 15%、GCS 全遮 15%。每項為三折 AP 平均，兩次 shift/mapped 再平均。

候選未遮蔽及 GCS 全遮 AP 皆不得比原 P33 低超過 0.003。只有最佳合格候選的加權目標比 P33 高至少 0.001 才接受；否則保留 P33，不進行新候選的 Set C／Demo 計分。平手依 clean、full_gcs、候選固定順序處理。

通過時封存規則與來源雜湊後，才使用既有全 A/B 的 P26/P28/P33 成分，在相同 Set C 固定遮蔽及尿量對齊的 Demo 兩種取樣計分。所有成分不再重訓，P55／P53 保存的同病例機率可重用，且需核對來源與 ID。

不因外部點估計不理想重新選規則，不以本輪增益保證外部改善。這是原三折上的增量開發實驗，未另外宣稱巢狀交叉驗證的無偏效能估計。
