## 適用範圍

- 全部結果比較的是同一批已評估過的 Set C，遮蔽在原先有觀測的 stay 中均勻選取。這能量化固定模型對這些通道的敏感程度。實際 eICU 的缺失可能和病況、檢驗決策、院別接口及通道間共缺有關。[ICU 缺失機制研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC6329436/)
- 匹配的是有至少一次觀測的比例。保留觀測的 stay 沿用 Set C 的量測次數、時間與數值。全遮蔽情境把指定欄位推到結構性缺失，分數同時反映原管線的補值及缺失特徵。
- 六項聯合匹配後的 AP 為 Full 0.5225、Elastic 0.5179。[P8 eICU 主分析](P8_eicu_demo_results.md) 為 0.4621 和 0.4766。兩份隊列仍有死亡比例、量測分布和其他欄位覆蓋差異，這些點估計適合並列描述。
