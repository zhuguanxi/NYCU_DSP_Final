MA-GBT 的研究動機是減少預測需要使用缺失值的情況，並同時衡量預測能力。本專題將補值依賴率與 AP 分開，而非把依賴率下降當成效能必然提高。 [ICML／PMLR 原文](https://proceedings.mlr.press/v267/stempfle25a.html) · [已鎖定作者版本](https://github.com/Healthy-AI/malearn/tree/fbbdd0ca2c9d0d8072f49d82ad35f4391098863f) · [本機實驗索引](../related_work/MA-GBT/README.md)

KEDGN 以文字醫學知識建立變數表示，並隨觀測密度調整變數間圖結構。本機作者排程測試 AP 為 56.8% ± 1.7%、AUROC 88.0% ± 0.8%，接近所用論文 ChatGPT 變體的 57.1%／87.9%；± 是五種子標準差。這不是 Set C 結果。A+B 重訓後 Set C 的五種子機率平均 AP 為 0.57502。 [NeurIPS 原文](https://proceedings.neurips.cc/paper_files/paper/2024/file/7c04aea54c2a60a632a47bd451cd2849-Paper-Conference.pdf) · [作者 GitHub](https://github.com/qianlima-lab/KEDGN) · [本機重現、種子與版本](../related_work/KEDGN/README.md)

## 本專題如何與文獻對話

核心不是宣稱新的通用圖網路，而是檢驗三種常被混用的能力：完整量測下的風險排序、指定缺失下的韌性、以及跨資料庫轉移。MA-GBT 提供「少依賴補值」的機制對照；KEDGN 提供經實際重現的不規則序列競爭基準；P33 則為表格、缺失專家與輕量序列的組合。

嚴格結論以同一病例、相同死亡標籤和觀察窗的凍結比較為主。KEDGN A+B 與本組使用相同 8,000 筆開發病例，但 KEDGN 的 36 個動態通道、9 個靜態值、正值 mask、平衡採樣及五種子平均，與表格／CNN 流程並不完全相同。作者切分成績保留作復現核對，不替代共同 Set C 成績。

目前可支持的敘事是：P33 在固定 P12 Set C 的完整與指定缺失情境都有改善，而降低補值依賴與跨庫 AP 增益並不等價。Demo 的 AP 區間跨零是研究結果的一部分，不能以文獻原表或本組單一高分取代。
