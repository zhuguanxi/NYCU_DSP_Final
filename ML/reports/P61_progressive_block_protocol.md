# P61：漸進隨機小時缺失與連續區段缺失

2026-11-22，讀取新結果前固定。Set C 全體 4,000 次住院／585 次死亡；沿 P60 固定五種子的七個模型，及既有 A+B KEDGN 五種子，全部保留，不選最佳種子／遮蔽位置。無新增訓練或調參。

對象為 GCS 單欄，以及 GCS、乳酸、侵入式 MAP、鎂、尿量、機械通氣六欄聯合。每名住院在 48 個時鐘小時中，隨機移除 12／24／36 格，對應 25%／50%／75%；對照為連續 12／24／36 小時區段。不是移除同比例患者，也不保證移除同比例有效觀測。聯合情境的六欄使用相同時段，模擬共同量測中斷。入院靜態資訊、其他通道、病例、標籤、分母與觀察窗保持不變。

每種設計三組位置，seed=2026112261+repeat。隨機小時用每名患者固定的 48 小時排序取前 L 格；區段起點=floor(U×(49−L))，同名患者同 repeat 沿用同一 U，各強度的區段及隨機集合均巢狀。時間 2,880 分鐘按原 P33 規則歸最後一格。位置產生不依標籤或模型分數。

共 36 個部分缺失案例，加未遮蔽、GCS 全遮、六欄全遮三個端點，合計39個案例。各案例先移除目標通道對應小時的原始清理後事件，再同步重算其全部表格統計、count／missing／defined、時間摘要及逐小時中位數／mask。不只改 CNN，不讓原摘要洩漏被刪資訊。clean 重建的六欄必須符合原特徵，未受影響欄位須逐值相同。

KEDGN 保留原作者時間網格與序列長度，只在相同住院、通道及時鐘小時把原值歸零，依原訓練統計建立作者正值 mask。其0／100%端點須重現P55；既有五種子均使用，不再擬合。不同表示的原始缺失定義仍不完全相同。

完整保存五個模型種子×三個位置的交叉結果；種子差異與位置差異分別報告，不將15個觀測視為15個獨立患者測試。主指標AP，另報AUROC、Brier、@0.5敏感度、相對各自clean的AP損失與實際刪除事件比例。圖中平均與波動說明是種子／位置描述，不冒充正式95%區間。五種子機率平均另標集成，KEDGN原seed0–4不與本組42–46假裝配對。

主要預先指定對比為50%時的隨機24小時與連續24小時（GCS／六欄各一組）：對本組每個種子，先算三組位置的AP平均差與相對clean的損失差，另提供五種子機率平均的1,000次住院配對bootstrap，seed2026112262。固定模型區間不包含完整重訓或歷史模型搜尋變異，未作多重比較修正，探索性解讀。其餘強度完整列出，不依曲線挑新配置。
