## 適用範圍與重現

強度選擇與重新擬合只用 A/B。Set C 和 eICU 均曾評估，本輪為同病例的回溯比較。人工尿量缺失之下的效果反映既有模型、補值和其他共同缺失欄位，eICU 仍有資料接口、量測與病例分布差異。

從 `DSP` 的 PowerShell 執行。使用新輸出路徑，比較程式會讀取既有的 P10、P11 產物。

```powershell
.\ML\.venv\Scripts\python.exe .\ML\src\train_missingness_augmentation.py --urine-only --output .\ML\artifacts\urine_only_AB_rerun
.\ML\.venv\Scripts\python.exe .\ML\src\evaluate_missingness_augmentation.py --models .\ML\artifacts\urine_only_AB_rerun --output .\ML\artifacts\urine_only_evaluation_rerun
.\ML\.venv\Scripts\python.exe .\ML\src\compare_urine_augmentation.py --models .\ML\artifacts\urine_only_AB_rerun --evaluation .\ML\artifacts\urine_only_evaluation_rerun --output .\ML\artifacts\urine_only_comparison_rerun
```

模型及 A/B 記錄在 `ML/artifacts/urine_only_augmentation_AB/`。全部四組指標、336 筆遮蔽配對彙總和四組 eICU 比較在 `ML/artifacts/urine_only_comparison/`。資料、模型和本機輸出均由 Git 排除。
