# P11 GCS-only 缺失增強規格

沿用 [P10](P10_augmentation_protocol.md) 的 P12 A/B 三折、兩個原特徵集合、已擬合前處理及 XGBoost 超參數。只對 GCS 建立遮蔽副本。所有訓練和選擇使用 CPU 2 執行緒，且只讀 A/B。

## A/B 選擇

- 比較 25% 與 60% 兩種強度。百分比是訓練折原有 GCS 觀測中被選取產生副本的比例。每個被選取的 stay 保留原列與一個 GCS 遮蔽副本，各給 0.5 權重。其餘原列權重 1。同步處理 GCS 的所有摘要、次數與缺失旗標。
- 使用原種子和抽樣方式。A/B 驗證分為未遮蔽、三次 25% GCS 遮蔽及一次 GCS 全遮。缺失分數是兩種 GCS 遮蔽情境等權平均的三折 AP。
- 以 Full 選單一強度，優先在未遮蔽平均 AP 較凍結折模型下降不超過 **0.0050** 的方案中，選缺失分數較高者。若兩案都超過，挑未遮蔽平均 AP 較高者，記錄門檻狀態。完全同分使用較低強度。
- Elastic 共用 Full 選定強度，完成三折診斷。再以全 A/B 對兩個模型各做一次擬合並保存。預計 11 次新擬合。這一階段的模型及紀錄另外保存。

## 固定評估

- 模型保存後，執行 [P9](P9_missingness_results.md) 的未遮蔽 Set C 和全部 13 種遮蔽，以原種子保留同樣的 32 次遮蔽位置。沿用 [P8](P8_eicu_demo_results.md) 的 eICU Demo 隊列、每小時和原生頻率特徵、病人叢集 bootstrap 和閾值 0.5。
- 同時以原凍結 Full／Elastic 和 [P10 GCS＋尿量增強](P10_augmentation_results.md) 為對照。主要比較 Set C 未遮蔽 AP 和 GCS 全遮 AP。報告相對於兩種對照的絕對差、AUROC、Brier 及固定閾值敏感度。以相同重抽樣估計 eICU AP、AUROC 的配對差值區間。
- Set C 與 eICU 結果皆用於凍結後的回溯比較。資料、模型和逐筆資訊置於 Git 排除路徑。
