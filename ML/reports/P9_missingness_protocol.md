# P9 Set C 缺失壓力測試規格

使用 P12 Set C 的 4,000 筆既有特徵與院內死亡標籤，沿用 P12 A/B 訓練的凍結 Full／Elastic XGBoost。模型、補值、選定欄位及 0.5 閾值固定。使用 CPU 2 執行緒。以下設定在計分前固定。

## 遮蔽設計

| 通道 | eICU Demo P8 有觀測的 stay | Set C 主分析目標 |
| --- | --- | --- |
| GCS | 583/782（74.55%） | 保留 2,982 次有觀測 stay |
| Lactate（乳酸） | 233/782（29.80%） | 保留 1,192 次有觀測 stay |
| MAP（侵入式平均動脈壓） | 174/782（22.25%） | 保留 890 次有觀測 stay |
| Mg、Urine、MechVent | 各 0/782 | 分別完整遮蔽 |

目標筆數按 [P8 覆蓋率](P8_eicu_demo_results.md) 乘以 Set C stay 數，四捨五入至整數。保留 Set C 原有缺失，只在原先有觀測的 stay 中均勻不放回抽樣，遮蔽至目標覆蓋率。若原始覆蓋率已較低，保留現有比例。

- **eICU 比例主分析**：GCS、Lactate、MAP 各自匹配覆蓋率，另跑三項聯合。Mg、Urine、MechVent 各自及三項聯合全遮蔽。再把六項一起按這些規則遮蔽。
- **全遮蔽敏感性分析**：GCS、Lactate、MAP 各自完整遮蔽，並跑六項全部遮蔽。Mg、Urine、MechVent 的全遮蔽結果與主分析相同。
- 含隨機抽樣的情境使用 32 次遮蔽，固定種子 20261116。各通道分開抽樣，同一重複內沿用相同通道的遮蔽位置，供單項與聯合情境配對比較。兩個模型使用同一批遮蔽。
- 遮蔽的單位為單次 stay 的整項動態通道。摘要設為空值，`count` 設為 0，`missing` 設為 1，`std_defined` 和 `slope_defined` 如存在則設為 0。侵入式 `MAP` 與非侵入式 `NIMAP` 保留各自欄位。

## 指標與判讀

以重新評分的未遮蔽 Set C 為配對基準，逐模型報告 AP、AUROC、Brier 與固定閾值下的敏感度。差值定義為遮蔽後減原基準。隨機情境報告 32 次的平均及遮蔽重抽樣的第 10–90 百分位。百分位反映固定 Set C 上抽遮蔽位置的變動。

模擬的是各通道的邊際覆蓋率。eICU 的缺失可能與病況、量測決策、院別接口及其他通道共同相關，且兩份資料的量測頻率與病例組成也不同。Set C 先前已評估過，這輪定位為回溯壓力測試。來源見 [PhysioNet 2012 挑戰](https://moody-challenge.physionet.org/2012/) 與 [eICU Demo](https://physionet.org/content/eicu-crd-demo/2.0.1/)。

原始資料、模型和個案層級特徵留在 Git 排除目錄。這次的評估產物包含每次遮蔽的彙總指標、覆蓋率與執行清單。
