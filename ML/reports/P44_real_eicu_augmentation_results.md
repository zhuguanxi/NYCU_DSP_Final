# P44 真實 eICU Demo 病例增強訓練

這輪把真實外部病例納入訓練，補足 [課程資料準備規格](<../../Term Project Requirements 2026 Fall-20260928/Term Project 2026 Fall.pdf>)。相較 P36 用外部量測分布模擬 P12 的缺失，P44 直接加入有臨床量測與住院死亡標籤的合格 eICU Demo 病例。沿用 8,000 次 P12 A/B stay、原 48 小時前處理與尿量 mL 對齊。每個 Demo 訓練 stay 權重為 1。重擬 P26 的時間窗 XGBoost 與 GCS 全遮 LightGBM，保留 P28 的 GCS-only Elastic 與原混合權重。全程 CPU，依 [P44 規格](P44_real_eicu_augmentation_protocol.md) 固定設定。

## Demo 切分與資料出處

782 次 Demo stay、719 人、91 次住院死亡均得到一次折外預測。每折只把其餘四折 Demo 的真實資料加入全 A/B。每一折的訓練與測試都沒有重疊患者或 `hospitalid` 連結區塊。五折的測試樣本數依序為 157、156、157、156、156，住院死亡數為 18、18、19、18、18。最終給 Set C 用的兩個分支使用全 A/B 和 782 次 Demo stay。

本機與公開下載的患者表和醫院表雜湊相符，兩表都含同樣的 186 個院鍵，合格隊列為 180 個。發布頁文字提到 20 家醫院，實際醫院數無法由這些來源確認。分折使用原始院鍵與患者識別鍵。每位患者的全部 stay 和其連結院鍵都分到同一折。[PhysioNet eICU Demo](https://physionet.org/content/eicu-crd-demo/2.0.1/) · [院鍵資料字典](https://eicu.mit.edu/eicutables/hospital/)

## eICU Demo 五折結果

先逐值核對兩個凍結對照，再比較合併的折外分數。1,000 次患者配對 bootstrap 的區間反映這組折外預測在患者重抽時的變動。

| 對齊與取樣 | 凍結 Elastic AP | P28 AP | P44 AP | P44 對 P28 AP 差與 95% 區間 |
| --- | ---: | ---: | ---: | --- |
| 原對齊，整點 | 0.47665 | 0.49382 | 0.50318 | +0.00935 [−0.01262, +0.03207] |
| 原對齊，原始間隔 | 0.46242 | 0.48922 | 0.50274 | +0.01351 [−0.00966, +0.03722] |
| 尿量對齊，整點 | 0.48957 | 0.50144 | 0.50754 | +0.00610 [−0.01807, +0.03246] |
| 尿量對齊，原始間隔 | 0.47724 | 0.49916 | 0.50823 | +0.00906 [−0.01706, +0.03568] |

四種設定的 AP、AUROC 點估計都高於 P28，配對區間都包含零。尿量對齊整點的 P44 AUROC 為 0.83609、Brier 為 0.07840、0.5 門檻敏感度為 17.58%。同一設定的 P28 分別為 0.82946、0.08015、13.19%。P44 相對凍結 Elastic 的 AP 差為 +0.01797，95% 區間 [−0.02640, +0.05849]。

## Set C 凍結評估

沿用全部 4,000 次 stay、585 次住院死亡及 P9 的 13 種遮蔽。整體模型用全 A/B 與合格 Demo 擬合完才在 Set C 給分。

真實病例增強在同批 Demo 的折外點估計有增益，Set C 對上一輪凍結 P28 的增益仍不確定。Demo 先前已用於資料對齊與探索，重抽區間也以已有的折外模型為條件。研究需要有授權的完整版 eICU 才能做預定的 [P40 獨立驗證](P40_eicu_sequence_confirmation_protocol.md)。
