# P45 真實 eICU 病例增強的分支消融

依 [P45 規格](P45_augmentation_branch_ablation_protocol.md)，用 CPU 比較凍結 P28、P44 雙分支增強、僅替換有 GCS 的 XGBoost，以及僅替換無 GCS 的 LightGBM。沿用 GCS-only Elastic 和原混合權重。Demo 重現 10 次原五折分支擬合。Set C 使用已存在的原 P28 和 P44 模型，新增最終擬合 0 次。

Set C 核對全體未遮蔽及原 13 種遮蔽的 168 次抽樣。兩個原模型的指標均重現。直接組裝的兩個單分支模型也在未遮蔽 Set C 逐值重現路由切換的預測。GCS 全遮時，只增強有 GCS 分支逐值重現 P28，只增強無 GCS 分支逐值重現 P44。

## eICU Demo

沿用 P44 的患者與院鍵區塊五折。每種取樣共 782 次住院、719 名患者、91 次死亡。表中為折外 AP，對照區間使用 1,000 次患者配對重抽。

| 設定 | P28 | 只增強有 GCS 分支 | 只增強無 GCS 分支 | P44 雙分支 | 有 GCS 分支對 P28 差與 95% 區間 |
| --- | ---: | ---: | ---: | ---: | --- |
| 原對齊，整點 | 0.49382 | 0.50578 | 0.49097 | 0.50318 | +0.01195 [−0.00742, +0.03176] |
| 原對齊，原始間隔 | 0.48922 | 0.50231 | 0.48953 | 0.50274 | +0.01308 [−0.00684, +0.03471] |
| 尿量對齊，整點 | 0.50144 | 0.51115 | 0.49778 | 0.50754 | +0.00971 [−0.01335, +0.03271] |
| 尿量對齊，原始間隔 | 0.49916 | 0.50653 | 0.49864 | 0.50823 | +0.00736 [−0.01525, +0.03220] |

只增強有 GCS 分支時，四種設定的 AP 點估計都高於 P28，區間均包含零。尿量對齊整點比 P44 的 AP 高 0.00361，配對區間 [−0.00868, +0.01653]。此設定的 AUROC 為 0.83666，Brier 為 0.07842，0.5 門檻敏感度為 16.48%。

在尿量對齊整點，有 GCS 的 583 次 stay 中有 69 次死亡，增強該分支後，這組 AP 由 0.51974 升到 0.53188。沒有 GCS 的 199 次 stay 有 22 次死亡，增強該分支後，這組 AP 由 0.46718 降到 0.44575。這些是分層點估計。合併 AP 也受到兩組患者之間的分數排序影響。

只增強有 GCS 分支保留了 P44 的主要折外增益方向，並按分流規則重現 P28 的 GCS 全遮分數。相對 P28 與 P44 的 Demo 差值仍不確定。這輪在既有資料上的消融屬探索性比較。完整版的主要確認仍依 [P40](P40_eicu_sequence_confirmation_protocol.md)。

所有情境、分層指標、配對區間及原模型來源保存在 Git 排除的 `artifacts/p45_augmentation_branch_ablation/`。
