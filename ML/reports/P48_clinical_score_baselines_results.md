# P48 同一隊列的臨床評分比較結果

P33 在有完整臨床評分的 Set C 子集，未遮蔽 AP 為 0.59781，高於原凍結 Full 的 0.57479。在有 APACHE IVa 風險的 eICU Demo 子集，P28 尿量對齊整點 AP 為 0.50101，APACHE IVa 為 0.37643，配對 AP 差 +0.12458，95% 區間 [+0.01155, +0.22301]。 [P48 固定規格](P48_clinical_score_baselines_protocol.md)

## P12 Set C

SAPS-I、SOFA 都使用官方發布的分數。兩項均有效的 A/B 有 7,491 次 ICU 住院、1,058 次住院死亡，對各評分分別擬合一個機率轉換。SAPS-I 的分數斜率為 0.117506，SOFA 為 0.133988。兩項的 AP 和 AUROC 均逐值核對到與原分數排序相同。 [PhysioNet P12 分數與標籤定義](https://physionet.org/content/challenge-2012/1.0.0/#outcome-related-descriptors)

Set C 共 4,000 次 ICU 住院、585 次住院死亡。SAPS-I 有 166 次、SOFA 有 122 次無有效分數，兩組缺失有重疊。共同隊列納入 3,769 次（94.2%）及 541 次住院死亡，排除 231 次、44 次住院死亡。最下方的序列混合模型沿用既有凍結預測。
