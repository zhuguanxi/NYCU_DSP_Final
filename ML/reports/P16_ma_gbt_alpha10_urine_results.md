# P16 MA-GBT 尿量缺失增強結果

加尿量增強後，Full／Elastic 在 Set C 尿量全遮與 eICU Demo 的補值尿量依賴率均為 0%。三個對照在同樣情境均為 100%。相對上一輪增強，尿量全遮 AP 提高 0.0249／0.0374，六項按 eICU 覆蓋率遮蔽的 AP 提高 0.0126／0.0329。整點 eICU 的 AP 也小幅上升，兩個配對區間均包含零。

依 [P16 規格](P16_ma_gbt_alpha10_urine_protocol.md) 執行。全程 CPU，完成 12 次 A/B 三折與 2 次最終擬合。沿用 alpha=10、GCS 45%／ICU 類型 75% 的遮蔽與原前處理。兩組最終擬合都保留 8,000 次 stay、1,122 次住院死亡，同一批 GCS 3,542 筆及 ICU 類型 6,000 筆被遮蔽，另各遮蔽 5,840 筆尿量。

## 限制與產物

- 尿量依賴率計算直接使用補值尿量統計量的預測路徑。量測次數與缺失旗標屬於已知輸入，單獨與尿量統計量解讀。GCS-only 的路徑採 XGBoost 原生葉節點，並核對原凍結前處理及分數。
- eICU Demo 的原欄位對齊把尿量視為缺失，且這批 Demo 已用於先前比較。外部差異的區間反映這批樣本的抽樣變異。
- 完整模型、Brier、0.5 門檻敏感度、模型分裂計數、來源雜湊及 336 筆遮蔽配對彙總保存在 Git 排除的 `ML/artifacts/ma_gbt_alpha10_urine/`。
