# P58：同一主模型的準確性、韌性與外部轉移

主模型固定為 P33，不依測試情境切換到各情境最高分的模型。P26 保留為重度缺失專家對照。全部結果使用已凍結分數，新增擬合 0 次。

## Set C 同病例結果

| 情境 | Full AP | P33 AP | ΔAP | 95% 配對區間 |
| --- | ---: | ---: | ---: | --- |
| clean | 0.57985 | 0.60447 | +0.02462 | [+0.01109, +0.03775] |
| full_GCS | 0.45383 | 0.53213 | +0.07830 | [+0.05838, +0.09808] |
| full_all_six | 0.43246 | 0.48911 | +0.05665 | [+0.03491, +0.07753] |

三個固定情境的 AP 差值區間都高於零，支持同一模型在未遮蔽及指定遮蔽下優於 Full，並非需要事後各選一個測試贏家。

兩個損失差的區間均高於零，支持 P33 的優勢同時包含較小的 AP 退化。人工全遮蔽仍不能代表所有臨床量測機制。

## 證據界限

Set C 未參與擬合，但已多次查看；這是固定模型的探索性整合證據。2,000 次住院配對抽樣與 1,000 次患者配對抽樣沿原種子，未校正跨歷史模型搜尋，也未涵蓋重新訓練／跨醫院變異。P56 的新條件混合在 A/B 未勝出，故本輪保留原 P33。
