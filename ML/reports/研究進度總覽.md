## 研究問題與共同設定

目標是同時衡量未遮蔽排序、缺失韌性和跨資料集轉移。MA-GBT 作為利用缺失矩陣限制補值依賴的方法對照，XGBoost Full／Elastic 提供固定表格基準。後續時間窗、分流與序列模型都保留各自的消融紀錄。

| 資料與觀察窗 | ICU 住院次／死亡 | 開發與用途 |
| --- | ---: | --- |
| P12 A/B，48 小時 | 8,000／1,122 | 原三折選參、增強強度與混合規則，最終全 A/B 擬合 |
| P12 Set C，48 小時 | 4,000／585 | 凍結模型比較及固定缺失壓力測試 |
| P12 A/B，24 小時代理隊列 | 7,817／1,071 | 同原三折的 24 小時模型開發 |
| P12 Set C，24 小時代理隊列 | 3,906／549 | 同觀察窗的凍結評估 |
| eICU Demo，48 小時 | 782／91 | 凍結遷移和患者／院鍵區塊五折增強 |
| eICU Demo，24 小時 | 1,398／121 | 前 24 小時遷移與增強，共同 APACHE IVa 隊列為 1,166／100 |

P12 標籤為官方住院死亡，eICU 用住院出院狀態對齊。表格有 435 欄，Elastic 最終保留 322 欄，仍涵蓋 37 個動態變數。時間摘要另有 20 通道、140 欄。序列表示保留各通道數值與觀測旗標。原始清理、單位、欄位定義和各折內估計的補值／縮放由個別階段規格記錄。

主指標為 AP，另報 AUROC、Brier 和固定門檻敏感度。Set C 用住院次配對重抽，eICU 主要用患者配對重抽，另檢查院鍵區塊敏感度。eICU 增強採同折患者和院鍵區塊互斥。 [前處理](P0_資料與特徵重建.md) · [24 小時條件](P49_24h_landmark_protocol.md) · [eICU 增強分折](P44_real_eicu_augmentation_protocol.md)

### 無改善或有取捨的結果

- GCS＋尿量增強提高 GCS 全遮表現，但未遮蔽 Set C AP 下滑。GCS-only 回收較多未遮蔽分數，成為後續韌性對照。尿量-only 兩個候選都超出原 A/B 未遮蔽損失門檻，依已記錄的備用規則完成消融。 [P10](P10_augmentation_results.md) · [P11](P11_gcs_only_results.md) · [P12](P12_urine_only_results.md)
- MA-GBT 的增強能降低補值依賴。尿量與乳酸依賴可降至零，加入膽紅素增強後 Elastic 任一補值依賴由 58.44% 降至 32.99%。eICU AP 的配對差仍跨零，GCS 全遮也出現小幅下滑。 [P16](P16_ma_gbt_alpha10_urine_results.md) · [P18](P18_ma_gbt_alpha10_lactate_results.md) · [P20](P20_ma_gbt_alpha10_bilirubin_results.md)
- 移除量測頻率欄位、依觀測量調整序列權重、按通道觀測分布訓練增強及三網路平均，都有 A/B 未勝過原配置的紀錄。這些消融支撐保留既有模型的決定。 [P31](P31_monitoring_ablation_results.md) · [P35](P35_sequence_gate_results.md) · [P36](P36_profile_sequence_results.md) · [P39](P39_sequence_seed_ensemble_results.md)
