# P35 依量測小時數調整序列權重

P35 檢驗序列觀測不足時降低序列分數權重，能否保留 Set C 表現，以及減少跨到 eICU 的排序損失。固定預測窗、標籤、原 A/B 三折、P28 表格分數與 P33/P34 序列檢查點。全程 CPU。

- 用 P34 稽核的來源，彙總 eICU Demo 的尿量、GCS、侵入式 MAP 每次 stay 有觀測的小時數直方圖，包括零小時。資料只用於描繪量測分布，未依 Demo 結果標籤選規則。
- 在 A/B 驗證的兩個原尿量部分恢復版本，分別以固定種子減少上述三個通道的覆蓋。覆蓋以 Demo 的可觀測比例換算，僅在 P12 原有紀錄範圍內隨機保留。對被保留的 stay 從 Demo 已觀測小時數直方圖抽樣，最多保留 P12 的原有小時數，再在有資料時點中隨機取樣。其他變數不變。
- 這兩個新的驗證版本只變動序列成分的輸入，沿用原對應版本的 P28 分數，以隔離序列分支的敏感度。結果不是完整跨庫機制的重現。六個原 A/B 版本同樣納入。
- 比較 P33、P34 各自的固定 25% 權重，以及按每次 stay 的原始觀測小時數選權重。門檻為尿量至少 8、16、24 小時，並且 GCS 至少 0、6、10 小時。低權重為 0 或 0.10，高權重為 0.25 或 0.40。P28 單獨計分作對照。
- 相對 P33，未遮蔽 AP 容許低 0.003，GCS 全遮 AP 容許低 0.005。合格者最大化未遮蔽、原跨庫模擬、尿量部分恢復、GCS 全遮、兩個新觀測版本平均的加權分數，權重依序 0.35、0.10、0.15、0.15、0.25。同分取較高未遮蔽 AP。
- 如選定門檻，沿用既有兩個凍結成分，依相同 Set C 遮蔽及 eICU 映射評估。若保留原固定配置，沿用原評估。正式完整版仍依 P29 規格。
