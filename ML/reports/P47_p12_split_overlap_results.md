# P47 P12 拆分與觀測重複稽核結果

依 [P47 規格](P47_p12_split_overlap_protocol.md) 用 CPU 核對 A、B、C 共 12,000 次住院。全部原始內容與既有對齊雜湊相同，原 P12 結果表的死亡標籤與凍結研究標籤一致。三組 RecordID 互斥，擬合 0 次。

## 原始及前處理輸入比較

| 跨組配對條件 | A–B | A–C | B–C |
| --- | ---: | ---: | ---: |
| 移除 RecordID 後完整紀錄相同 | 1 | 0 | 0 |
| 非空的標準化動態事件集合相同 | 0 | 0 | 0 |
| 435 個凍結特徵相同 | 1 | 0 | 0 |
| 動態觀測合格且 Jaccard 至少 0.90 | 0 | 0 | 0 |

高重疊檢查的最小條件為 40 個不同事件、3 種變數及 12 個觀測分鐘。A、B、C 各有 3,947、3,943、3,959 次住院符合條件。對 46,799,531 種合格的跨組組合，依必要重疊下限篩選後，沒有候選達到需作交集計算的條件。以合成事件集合和逐對交集核對了篩選，含恰好落在 0.90 的情形。

A–B 的兩項相同是同一對住院。兩筆都沒有有效動態事件，原死亡標籤相同。這一對分屬原 A/B 三折的不同驗證折。只從已凍結的折外分數中排除這兩筆，三折平均 AP 的變化如下。

| 模型 | 原 AP | 排除兩筆 AP | 差值 |
| --- | ---: | ---: | ---: |
| 凍結 Full | 0.54499355 | 0.54499556 | +0.00000201 |
| 凍結 Elastic | 0.53851783 | 0.53851911 | +0.00000128 |
| P28 | 0.56072138 | 0.56072197 | +0.00000059 |

這是在給定原折外分數下，排除兩筆對 AP 的直接變化。重新擬合後的影響未知。從 `features_AB.parquet` 比對 435 欄相同的跨組輸入，接 `labels_AB.csv` 與 `folds3.csv`，即可核對病例數與分折。Full、Elastic 使用各自 A/B 原 run 的 `oof.csv`。P28 使用 P33 A/B 原資料包的未遮蔽表格分數。

Set C 與 A/B 之間在上述檢查皆未找到重複。P12 提供 ICU stay 的 RecordID，同一患者跨住院的身分無法從這些識別鍵判定。[PhysioNet P12 資料與識別鍵定義](https://physionet.org/content/challenge-2012/1.0.0/#general-descriptors)

稽核彙總及來源雜湊保留在 Git 排除的 `artifacts/p47_p12_split_overlap/`。完整版 eICU 的患者獨立驗證入口見 [P46](P46_eicu_adaptation_confirmation_protocol.md)。
