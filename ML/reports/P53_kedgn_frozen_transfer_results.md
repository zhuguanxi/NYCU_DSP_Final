# P53：凍結 KEDGN 的 Set C 與 eICU Demo 轉移評估

2026 年 11 月 21 日完成。R1 已取消，其他文獻背景重跑已停止。本輪僅載入既有模型做 CPU 推論，模型擬合 **0 次**，未調整參數、輪次、種子或前處理統計。資料、逐筆預測、權重及可回推病例的中間產物都留在 Git 排除的 artifacts；此文件與彙總 JSON 只含整體統計。

## 結果判讀

- Set C 的 KEDGN AP 為 **0.54977**，對凍結 Full 的差為 **−0.03008 [−0.05361, −0.00594]**，對 P33 為 **−0.05470 [−0.07657, −0.03171]**。在本輪固定模型與訓練方案下，兩組差值區間均低於零；對 Elastic 的 AP 區間則跨零。
- eICU 整點／原始間隔 AP 為 **0.44998／0.44596**，低於七組對照的點估計，但全部 AP 差值區間均跨零。對 P28 的差分別為 **−0.05146 [−0.11656, +0.02452]**、**−0.05321 [−0.11898, +0.02604]**。目前不能宣稱有改善，也不能確認外部效能的優劣。
- KEDGN 在固定 0.5 門檻的敏感度較高，但三個隊列的 Brier 都較七組對照高。較高敏感度不能單獨解讀成整體分類或臨床效益較好；本輪沒有重新校準或選門檻。

## Set A 還是 A+B？

建議分成兩個問題。本輪先用已凍結的作者 Set A 模型，回答「已重現的 KEDGN 能否轉移到我們兩個測試集」。其訓練是 Set A 的 3,198 筆，另有 400 筆驗證及 399 筆作者測試，並非完整 Set A 都用於訓練。本組原模型使用 A+B 的 8,000 筆。

若研究要主張共同訓練資料下的架構優劣，建議另外用本組 A+B 三折開發、固定輪次後全 A+B 重訓 KEDGN，保持 Set C 與 eICU 不參與選參。本輪依凍結模型要求沒有做這項重訓，因此下表不把訓練量、特徵表示和前處理的差異歸因於架構。

## 評估規則與核對

- 五個種子皆使用原驗證 AP 最佳 checkpoint，先重現作者獨立測試 399 筆／51 次死亡的每種子 AP、AUROC，再做轉移推論。原報告的五種子 AP 56.8% ± 1.7%、AUROC 88.0% ± 0.8% 是作者測試集成績，並非驗證分數，也不是 Set C。
- 主要分數事先固定為五個凍結種子的機率等權平均；另列各種子及指標平均／標準差。沒有用外部測試集挑最佳種子。
- Set C 使用相同 4,000 筆／585 次死亡；eICU 使用相同 782 次住院／91 次住院死亡、既定尿量 mL 對齊，分別計分整點與原始間隔。KEDGN 的 Set C ID 與訓練 ID 已核對互斥。
- 七組本組凍結模型均重新載入推論；Full／Elastic 的 Set C 預測與保存值逐值核對，其餘主要指標與既有結果核對。兩種 eICU 的七組指標亦均重現。病例順序及死亡標籤逐值核對。
- Set C 配對區間沿用 2,000 次住院次重抽，seed 20261013；eICU 沿用 1,000 次患者分組重抽，seed 42。差值方向均為 KEDGN 減對照，區間為固定模型下的 95% 百分位區間。未作多重比較修正，不能涵蓋重新訓練、醫院或資料庫間的全部變異。
- 本輪只評估未遮蔽輸入，沒有新增訓練或缺失壓力實驗。P45 使用 Demo 病例做折內增強、P52 使用 24 小時觀察窗，其問題與本輪 48 小時純轉移不同，未合併排名。

## 主要結果

AP、AUROC、敏感度越高越好，Brier 越低越好；敏感度沿用固定 0.5 門檻，沒有以測試集重新選門檻。

## 輸入適配與限制

1. Set C 按欄位名稱讀取入院靜態資料，修正 90 筆欄位順序或缺漏不同的紀錄；在 30 筆 Set A 樣本與作者快取逐值核對動態值、時間、靜態、擴展靜態及長度。Set C 的 2 筆零觀測病例保留，未為提高分數刪除。
2. KEDGN 保留作者 36 通道、9 維擴展靜態、正值 mask 與原始非正值處理。縮放統計只由原 3,198 筆訓練資料重建；靜態標準化行為也沿用作者。這與本組 435／322 欄表格、清理及補值表示不同。
3. 觀察窗沿用作者 minute < 2880。Set C 最大長度 214；eICU 整點最大 547、原始間隔最大 1,048 個時間點，分別有 127／764 筆超過作者訓練的 215 點。模型可依實際長度運算，因此全部保留；長序列本身仍是分布轉移。依 batch 長度 padding 至少 215，避免作者 T=60 的另一種時間單位分支。
4. eICU 的缺失欄位與不能直接對齊的測量仍可能影響結果，沒有用 Demo 估計補值或校準參數。這份 Demo 只有 91 次死亡，不能代替完整版 eICU 的獨立外部確認。
5. Set C 已在本專案反覆用於比較，適合透明報告凍結結果，不能再視為研究全程從未查看的測試集。各表差值是固定預處理與訓練方案的比較，不能單獨證明架構因果優劣。
