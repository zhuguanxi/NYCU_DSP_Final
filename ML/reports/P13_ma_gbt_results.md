# P13 原版 MA-GBT 對照結果

這版 MA-GBT 在未遮蔽 Set C、13 種遮蔽情境以及 eICU Demo 的 AP 均低於原凍結 XGBoost 與 GCS-only。GCS 全遮後，MA-GBT 的 AP 從 0.4464 降到 0.2465，下降 0.1999。Full／Elastic 的 MA-GBT 指標完全相同。兩者解碼後的 30 個樹內分裂使用相同的六個原始欄位，其中 GCS 最後值出現 11 次、GCS 最大值出現 1 次。Set C 全遮 GCS 後，每筆預測都用到補過的 GCS。

依 [P13 規格](P13_ma_gbt_protocol.md) 執行。八套前處理各與原凍結 XGBoost 逐值核對 8,000 筆 A/B。正式訓練前核對原版和數值加速版的樹切分、節點值、驗證預測與缺失依賴率，結果一致。模型在 Set C 和 eICU 評估前凍結，本輪只在 A/B 進行 14 次正式擬合。以 4 個 CPU 工作程序執行 A/B 三折，Full／Elastic 最終擬合各用 153.6／116.4 秒。

## 限制與產物

- 這輪測量的是原作者 MA-GBT 在 P12 固定前處理與有限 A/B 搜尋下的表現。與歷史 XGBoost 的差異同時包含模型與樹容量，因此對照之間的差值無法單獨估計缺失懲罰的效果。A/B 表格提供相同 MA-GBT 設定下不同懲罰的直接比較。
- ρ 計的是直接使用補值特徵的預測路徑。量測次數與缺失指標本身為已知輸入，模型仍能利用量測模式。
- 0.5 門檻沿用歷史設定。 eICU Demo 的樣本少，Mg、尿量與機械通氣仍沿用 P8 的未映射處理，外部差異同時涵蓋量測與族群變化。
- 完整 336 筆遮蔽配置的配對彙總、兩個模型、參考預測與雜湊均在本機 Git 排除目錄 `ML/artifacts/ma_gbt_p12/`。這份提交僅包含彙總報告。
