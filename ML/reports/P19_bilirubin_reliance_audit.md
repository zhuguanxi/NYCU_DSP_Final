# P19 膽紅素補值依賴與單欄遮蔽

乳酸增強後，Elastic 的整體補值依賴從 448 增到 457 筆（57.29% 到 58.44%）。這 9 筆淨增加可分解為只依賴膽紅素補值的預測增加 154 筆，以及使用至少一項非膽紅素補值的預測減少 145 筆。膽紅素是整體依賴上升的主因。

## eICU Demo 路徑

使用 P16 尿量增強、P18 乳酸增強及 P11 GCS-only 的凍結模型，保留 eICU 原整點和原始間隔、782 次 stay。全程 CPU，重算預測及原整體依賴通過核對。下表以整點為主，各格為 stay 數及比例。「只依賴膽紅素」指膽紅素是該次預測使用的唯一補值欄位。「至少用到一項非膽紅素補值」也包括同時使用膽紅素的 stay。兩欄相加得到整體。

| 組別 | 欄位 | 任一補值 | 膽紅素補值 | 只依賴膽紅素 | 至少用到一項非膽紅素補值 |
| --- | --- | ---: | ---: | ---: | ---: |
| 尿量增強 MA-GBT | Full | 404（51.66%） | 11（1.41%） | 2（0.26%） | 402（51.41%） |
| 尿量增強 MA-GBT | Elastic | 448（57.29%） | 140（17.90%） | 46（5.88%） | 402（51.41%） |
| 乳酸增強 MA-GBT | Full | 337（43.09%） | 115（14.71%） | 80（10.23%） | 257（32.86%） |
| 乳酸增強 MA-GBT | Elastic | 457（58.44%） | 296（37.85%） | 200（25.58%） | 257（32.86%） |
| GCS-only | Full | 782（100.00%） | 572（73.15%） | 0（0.00%） | 782（100.00%） |
| GCS-only | Elastic | 782（100.00%） | 354（45.27%） | 0（0.00%） | 782（100.00%） |

- 兩個 MA-GBT 的膽紅素補值路徑都來自最後值。Elastic 使用膽紅素的預測從 140 筆增到 296 筆。另以互斥順序計算，其他欄位先由 256 增到 257 筆，其上膽紅素新增的覆蓋由 97 增到 200 筆，其後乳酸新增的覆蓋由 95 降到 0 筆。合計 +1 +103 −95 = +9。
- 在 GCS-only，膽紅素補值相當常見。兩組所有 stay 都還使用其他欄位補值，所以只依賴膽紅素的比例是 0%。原始間隔下，GCS-only Elastic 的膽紅素依賴為 358 筆，整點為 354 筆。兩個 MA-GBT 的數字與整點相同。

路徑分解在固定預測下計數。移除缺失矩陣中某欄的標記，只改變該欄是否被計入依賴。Set C 在實際改動輸入後，另外量測 AP。

## Set C 膽紅素單欄遮蔽

使用原 4,000 次 stay、585 次住院死亡與凍結補值。Set C 膽紅素原覆蓋率為 1,768/4,000（44.2%），低於 eICU 的 429/782（54.9%），因此使用全遮與遮掉一半原觀測兩個情境。一半遮蔽每次遮 884 筆，共 32 次固定抽樣。三組模型的抽樣位置雜湊一致。只修改膽紅素統計量、量測次數及缺失／定義旗標。

| 組別 | 欄位 | 未遮蔽 AP | 全遮 AP | 全遮 ΔAP | 遮一半平均 ΔAP（第 10–90 百分位） |
| --- | --- | ---: | ---: | ---: | ---: |
| 尿量增強 MA-GBT | Full | 0.4160 | 0.4138 | −0.0022 | −0.0019 [−0.0040, +0.0000] |
| 尿量增強 MA-GBT | Elastic | 0.4204 | 0.4173 | −0.0031 | −0.0020 [−0.0052, +0.0009] |
| 乳酸增強 MA-GBT | Full | 0.4214 | 0.4113 | −0.0101 | −0.0046 [−0.0108, +0.0001] |
| 乳酸增強 MA-GBT | Elastic | 0.4158 | 0.4053 | −0.0105 | −0.0057 [−0.0123, +0.0012] |
| GCS-only | Full | 0.5775 | 0.5726 | −0.0049 | −0.0028 [−0.0046, −0.0008] |
| GCS-only | Elastic | 0.5710 | 0.5638 | −0.0072 | −0.0036 [−0.0058, −0.0021] |

第 10–90 百分位描述固定 Set C 更換遮蔽位置的變動。

## 優先順序

**若目標是降低乳酸增強後的 eICU 補值依賴，膽紅素值得優先檢查。** Elastic 有 200/782 筆預測只使用膽紅素這一項補值欄位，且該欄在 Set C 全遮的 AP 降幅約 0.011，半遮平均約 0.006。若目標是保護 AP，GCS 全遮仍是更大風險。P18 乳酸增強的 GCS 全遮 ΔAP 為 −0.1013／−0.0924，機械通氣全遮為 −0.0160／−0.0314。膽紅素的路徑集中與遮蔽損失應一起衡量。
