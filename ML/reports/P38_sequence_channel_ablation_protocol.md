# P38 尿量和呼吸率序列通道消融

P34 記錄了 P12 與 eICU Demo 的觀測差異。尿量在有紀錄者中的觀測小時中位數為 37 和 5，呼吸率在兩庫的覆蓋為 27.9% 和 90.2%。本輪檢查限制序列模型使用這兩個通道，能否提高 A/B 排序或減少測試情境間的落差。

- 分別從四小時序列卷積移除尿量、呼吸率、兩者。每次移除數值及觀測旗標，訓練與推論均使用同一通道子集。其餘序列與靜態輸入、原 48 小時窗、原 A/B 三折、P34 無增強訓練 8 回合及 CPU 設定維持。P28 表格模型仍使用原輸入及分數。
- 每組與 P28 比較序列權重 10%、15%、25%、40%，採機率加權或 P37 的對數勝算差截在 ±2。沿用 P37 的 A/B 情境、加權 AP、相對 P33 的未遮蔽與 GCS 全遮門檻。把 P33、P34、P37 納入同一排序，以 P28 作對照。
- 只在新增配置勝出時用完整 A/B 擬合一次，再以原 Set C 遮蔽及兩種 eICU Demo 取樣與對齊評估。P28、原凍結模型和 P34 共用同一隊列比較。若保留原配置，沿用既有評估。

在 `ML` 使用 [P33 的 Torch CPU 環境](P33_hourly_sequence_protocol.md) 及 P37 產物，執行 `src/train_sequence_channel_ablation.py`。選型及凍結模型保留在 Git 排除的 `artifacts/p38_sequence_channel_ablation/fitted/`。
